# Changelog

Future entries are maintained by semantic-release. The releases below were published before the automated release workflow was adopted.

## [0.2.0](https://github.com/ak800i/mixplorer-patches-for-morphe/releases/tag/v0.2.0) (2026-09-18)

- Added stable MiXplorer 6.71.15, ARM64 build 26090422, while retaining beta support.
- Verified stable startup, native single-file and two-file receiver reads, and same-UID path preservation on Android 13.
- Live Telegram UI/network uploads remain unverified.

## [0.1.0](https://github.com/ak800i/mixplorer-patches-for-morphe/releases/tag/v0.1.0) (2026-09-18)

- Initial sharing fix for MiXplorer 6.71.15-BETA, ARM64 build 26090412.
- Preserved content URI access and internal paths while hiding external `_data` values.
- Included the local-signing support required for the tested free beta.
